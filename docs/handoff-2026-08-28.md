## The one architectural decision worth restating

The admin Reviews list is assembled in the **server component**
(`app/admin/page.tsx`), not from `GET /api/reviews`. It merges three row sources:

1. real `reviews` rows,
2. placeholder rows for employees with a `self_reviews` row but no `reviews` row,
3. placeholder rows from `employee_review_cycles` for employees whose period has
   opened but who have started nothing.

Sources 2 and 3 are **read-only view rows — nothing is written to the database.**
Inserting real `reviews` rows would be wrong: `reviews.user_id` means "the manager
who authored this", and `POST /api/reviews` explicitly forbids employees from
creating them. Merging on read also self-heals — a placeholder disappears the
moment the manager starts the real review.

Rows carry `source: 'review' | 'self_assessment' | 'cycle'`. Anything that reads or
mutates a real review record (manager-review link, comparison, delete) is disabled
when `source !== 'review'`, because there is nothing behind those rows.

Progress weights live in one object, `PROGRESS_WEIGHTS` in `AdminDashboard.tsx`.
They sum to 100 and are additive. Adjusting the model means editing that object,
not hunting through the component.

## How to verify UI changes — non-obvious, and you will need it

**You cannot log in.** `/admin` is Google OAuth only, so there is no way to reach
it as the agent. The technique used all session:

1. Copy `app/admin/page.tsx` to `app/pending-preview-reviews/page.tsx`.
2. Replace the auth guard with a hardcoded `role = 'admin'` and a
   `if (process.env.NODE_ENV === 'production') notFound()` block.
3. Fix the import to `'../admin/AdminDashboard'` and drop the `user.email!` bang.
4. Load `http://localhost:3000/pending-preview-reviews`, click Reviews, screenshot.
5. **Delete the directory before committing** and confirm with `git status`.

The route name matters: `middleware.ts` matches public paths with
`path.startsWith(p)`, and `/pending` is public — so `/pending-preview-reviews` is
served without auth with no middleware edit. This renders the *real* component with
*real* production data.

Dev server: `preview_start` with name `performance-review-app` (`.claude/launch.json`,
port 3000). Browser-tool refs go stale after a reload; take a screenshot and click by
screenshot coordinates when `ref` clicks land in the wrong place.
